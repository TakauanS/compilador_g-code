# Compilador G-Code 

O compilador G-Code é uma aplicação desktop desenvolvida em Python para a criação otimizada de programas CNC paramétricos, um dos principais objetivos foi aumentar a produtividade do setor de usinagem da empresa onde atualmente trabalho, a AVB (Aço Verde do Brasil).

## 🚀 Começando 

Se deseja reutilizar e/ou testar o compilador G-Code, fique à vontade! Siga o passo a passo de instalação e, antes disso, confira os pré-requisitos.

## 🛠️ Construído com

O compilador G-Code foi desenvolvido utilizando diversas ferramentas ao longo do processo de criação, sendo elas:

- Customtkinter - Biblioteca de interface gráfica.
- Tkinter - Biblioteca de interface gráfica (Para as menssagebox).
- PIL - Biblioteca de processamento de imagens.
